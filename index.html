Input your dragon's info

1. Select all text on the dragon's profile from name to offspring.

2. Copy it, and paste it into the first window.

3. Press parse, and all information will be auto-filled into the table below!

How to use the BBcode Builder

1. To start, press "Add Block"

2. Type bbcode into "Text before" and "Text after" or select a premade block by pressing the "Pre-Made Blocks" button.

3. Select a variable from the middle drop down menu.

4. You can toggle additional options or add your own variables in the Extra Variables section.

4. Drag blocks around using the handle icon .

5. Some blocks (columns, hidden, ...) can have other blocks nested into them - drag a block into the gray backgroud area, or press on a nestable block to nest it into the block above it. Press to unnest it again. Press the minus icon "" to collapse all nested elements.

6. Copy bbcode to clipboard from the "Generated BBCode" window below.

7. To save your build for later use (or to share with others), click "Save Template". You can then copy the URL to share it, or bookmark the page. Drafts are saved automatically.
